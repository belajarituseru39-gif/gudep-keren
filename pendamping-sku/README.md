# Pendamping SKU

Aplikasi pendamping pembina untuk mencatat pengujian SKU peserta didik pada golongan Siaga, Penggalang, Penegak, dan Pandega.

## Menggunakan aplikasi

1. Buka halaman Pendamping SKU melalui tautan di README utama GUDEP KEREN.
2. Lengkapi identitas Gudep dan tambahkan atau impor peserta didik.
3. Pilih peserta, golongan, dan tingkat yang diuji.
4. Buka **Catatan uji** pada butir yang diperiksa, lalu simpan hasil pengujiannya.
5. Unduh laporan atau surat keterangan PDF jika semua butir tingkat tersebut telah lulus.

## Penyimpanan data

Aplikasi ini berjalan di browser. Data peserta dan catatan uji disimpan di penyimpanan lokal browser pada perangkat yang digunakan, tidak dikirim ke GitHub. Data tidak otomatis berpindah antarperangkat atau browser; ekspor cadangan secara berkala dan jaga akses ke perangkat.
